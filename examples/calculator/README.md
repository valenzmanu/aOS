# Calculator demo project

This deliberately small Python project is copied into a temporary Git repository by
`scripts/demo.sh`. The fake aOS worker does not modify it; it demonstrates that an authorized
mission is isolated, checkpointed, independently verified, and held for human approval.

After the fake run, repeat the mission with `--backend cursor` or `--backend codex` and an objective
such as “add subtraction with tests” to exercise a real provider against disposable code.
