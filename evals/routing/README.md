# E2E-ROUTING-01 — layered agent routing

This learning scenario asks whether a fresh liaison can rank models for a bounded task, expand
them into practical model/harness/billing routes, reject ineligible alternatives, and choose the
best expected cost-to-success route without inventing mutable facts.

The first slice uses a deterministic catalog and cost observations. After the fresh Codex process
starts, the runner waits and grades the authored route decision.

Run from the repository root:

```sh
uv run python evals/routing/run.py
```
